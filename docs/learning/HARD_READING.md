# 어려움 — 짧은 문장 읽고 그림 선택

먼저 작성한 [50문제 목록](HARD_QUESTIONS.md)을 실제 데이터인 `sentence-questions.js`로 옮겼습니다. 1단계 20개, 2단계 20개, 3단계 10개입니다. 세 선택지는 직접 그린 SVG이며 글자·숫자·이모지·외부 이미지에 의존하지 않습니다.

- 문장은 자동으로 읽지 않습니다. 뮤 설명 버튼과 오답 때 문장과 힌트를 읽습니다.
- 첫 오답은 핵심을, 두 번째부터 네 번째는 구체적인 비교 지점을 알려줍니다.
- **5연속 오답**에 정답 그림과 문장을 알려주고 포획 실패 상태를 유지합니다. 마지막에 포켓몬을 만나 볼을 던져도 포획은 실패합니다.
- 정답을 맞히면 연속 오답은 0이 됩니다. 창을 닫아도 오답 횟수가 저장되어, 닫았다 여는 방법으로 회피할 수 없습니다.
- 도움을 받았거나 정답을 안내받은 뒤 맞혀도 정상 학습·탐험 실적을 받습니다. 진급 판단용 학습 기록과 게임 보상은 구분합니다.

## 출제와 단계

새 문제는 화면에 표시한 순간 본 문제로 저장합니다. 보지 않은 나머지 문제는 창을 닫아도 소진되지 않습니다. 날짜가 바뀌어도 50개를 다 보기 전까지 반복하지 않습니다. 한 바퀴가 끝나면 다음 시작에서 문제 순서와 선택지 위치를 다시 섞습니다. 바퀴 마지막에 새 문제가 5개보다 적으면 남은 문제만 풉니다. 숲·바다 등 탐험 발자국은 기존처럼 이어집니다.

처음에는 1단계에서 출제합니다. 기본 진급 기준은 앞 단계 누적 정답 12개와 도움 없이 첫 시도에 맞힌 비율 70%입니다. 이후 이미 학습한 단계와 새 단계를 섞습니다. 낮은 단계의 새 문제를 모두 보면 진급 기준을 채우지 못했어도 남은 새 문제를 출제하므로, 기준 때문에 같은 문제를 반복하거나 진행이 막히지 않습니다.

부모님 메뉴의 **어려움 · 문장 읽기 단계**에서 2·3단계 진입 정답 수(1~100), 첫 시도 정답 비율(0~100%), 복습 허용을 조절합니다.

## 복습과 저장

틀린 문장은 별도 복습 목록에 저장합니다. 어려움 화면에서 ‘틀린 문장 다시 보기 · 복습’을 직접 선택하면 복습으로 표시됩니다. 복습은 새 문제 50개 목록을 소진하지 않습니다. 복습에서 정답을 맞히면 해당 문장을 복습 대기 목록에서 제거합니다.

`state.hardReading`에는 현재 바퀴, 본 문제, 문제 순서, 이전 선택지 배치, 문장별 정답·오답·도움 기록, 복습 목록, 연속 오답, 진급 설정을 저장합니다. 최근 완료 기록 500개에는 `isReview`를 명시합니다. 기존 TV 시간과 학습·도감 데이터는 유지합니다. 기존 ‘학습·도감 초기화’는 문장 학습 기록도 함께 지웁니다.

새 바퀴와 복습의 학습 실적에는 별도 ID를 사용합니다. 도움 사용에 따른 보상 삭감은 없습니다. 실적은 기존 포획·전설·이로치 기준에 연결되며, 5연속 오답의 포획 실패 규칙만 어려움에 별도로 적용합니다. 쉬움·보통의 기존 규칙은 변경하지 않습니다.

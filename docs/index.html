테스트 기록 정리

완료 기록 초기화는 오늘 완료 표시와 해당 보상 시간을 되돌립니다. 학습·도감 초기화는 학습·포획 기록만 처음으로 되돌립니다. TV 시간과 설정은 유지해요.

어려움 · 문장 읽기 단계

정답 수와 비율을 모두 채우면 다음 단계를 섞어요. 낮은 단계의 새 문제를 다 보면 남은 단계로 진행하며, 50개 전에는 새 문제를 반복하지 않아요. 도움 사용은 보상을 줄이지 않아요.

시간 직접 조절

하루 총 허용 시간은 최대 240분이에요. 앱 삭제·브라우저 데이터 삭제 시 기록은 복구할 수 없어요. 아이폰과 Mac 사이에 기록이 동기화되지는 않아요.

학습·도감 테스트 기록 초기화

퀴즈 성공 기록, 잡은 포켓몬, 아이템, 탐험 진행, 포획 대기 기록을 지웁니다. 미션 설정·TV 시간·얼굴 사진은 유지합니다. 지운 학습 기록은 복구할 수 없어요.

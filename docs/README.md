# 연우의 포켓 타임 웹 체험판

## 포켓몬 모험과 151종 도감

### 이로치 모습

151종의 실제 색이 다른 공식 아트워크를 별도 자산으로 포함합니다. 기본 포켓몬의 이로치는 보통 이상, 희귀·전설·환상 포켓몬의 이로치는 어려움 성공에서 등장할 수 있습니다. 이미 획득 조건을 충족한 포켓몬 중 아직 없는 이로치를 선택합니다. 보통 성공은 1/24, 어려움 성공은 1/16 확률이며, 보통 이상 누적 성공 20개마다 확정 만남을 제공합니다. 같은 날 같은 난이도를 재시도하거나 포획 연출을 다시 보는 것은 새 추첨을 만들지 않습니다. 쉬움에서 상위 난이도로 승급 성공한 경우는 새 도전으로 인정합니다. 모습은 실적 기록 시 저장하므로 새로고침으로 바뀌지 않습니다. 기본 도감은 유지하고 이로치 도감을 추가로 채우는 방식입니다. 미리보기는 획득에 반영되지 않습니다. 이 확률은 본 체험판의 규칙이며 원작 게임의 확률과는 다릅니다.

전설 포획에는 금빛 광선·등장 고리·별 입자·실루엣에서 나타나는 캐릭터 연출을, 뮤츠·뮤에는 보라색 특별 효과를 적용합니다. 도감의 ‘전설 등장 연출 미리보기’는 획득 실적이나 포켓몬을 추가하지 않습니다. 한국어 TTS 특별 안내와 동작 줄이기 설정을 지원하며, 효과 영상이나 원작 게임 영상은 사용하지 않습니다.

등장 화면에서 볼 던지기를 누르면 볼이 열리고 포켓몬이 빛으로 변해 들어간 다음, 볼이 닫히고 흔들리며 포획 성공을 표시합니다. 일반 포켓몬은 몬스터볼, 전설·상위 전설·환상은 마스터볼을 사용합니다. 연출 건너뛰기·포획 다시 보기를 지원하며 도감 실적을 중복 지급하지 않습니다. 포켓몬은 퀘스트 조건을 달성할 때 이미 저장되므로 창을 닫거나 연출을 건너뛰어도 획득 기록이 사라지지 않습니다.

도감은 독립된 ‘도감 보기’ 화면에서 열며, iPad·Mac에서는 왼쪽에 연우의 트레이너와 수집 현황, 오른쪽에 포켓몬 목록이 표시됩니다. iPhone에서는 트레이너가 목록 위에 표시됩니다. 부모 메뉴에서 사진을 선택하고 얼굴 위치·확대를 조절하면 직접 그린 모자·조끼 트레이너의 얼굴 부분에 표시합니다. 자동 얼굴 인식이나 인물 합성 모델은 사용하지 않습니다. 사진은 브라우저에서 최대 600px의 JPEG로 다시 그려 메타데이터 없이 별도 localStorage 키에 저장하고 서버로 전송하지 않습니다. 저장 전 취소할 수 있고, ‘사진 지우기’는 도감·보상 기록을 삭제하지 않습니다. 다른 기기에는 동기화되지 않습니다.

사진 선택은 도감과 부모 메뉴 양쪽에서 보이는 브라우저 기본 파일 선택 버튼을 사용합니다. HEIC를 포함해 이미지 선택을 허용하지만 실제 읽기는 기기 브라우저의 형식 지원에 따릅니다. 읽기 실패 시 열린 창 안에 원인 안내를 표시하고 JPG·PNG 또는 사진 캡처 이미지를 안내합니다. 실제 iPhone의 사진 보관함·HEIC 읽기는 별도 기기 확인이 필요합니다.

아이 화면의 포털은 ‘포켓몬 모험’으로 표시됩니다. 정답 1개를 퀘스트 1개로 기록하고, 누적 5개에 첫 파트너 이상해씨를 만납니다. 1세대 151종에 난이도별 획득 조건을 적용합니다. 기본 포켓몬은 모든 난이도 누적 5개 간격, 희귀 포켓몬은 보통 이상 누적 5개 간격입니다. 프리져·썬더·파이어는 보통 이상 50·60·70개, 뮤츠는 어려움 100개, 뮤는 어려움 90개 조건입니다. ‘상위 전설’은 이 앱의 보상 등급 이름입니다. 각 포켓몬의 조건은 도감에 표시됩니다. 같은 문제는 하루 한 번만 총 실적에 포함하고, 상위 난이도로 다시 성공하면 총 실적을 늘리지 않고 난이도 실적을 승급합니다. 다음 날 다시 풀면 새 실적으로 기록합니다. 기존 버전에서 획득한 포켓몬은 보존합니다. 누적 실적과 획득한 포켓몬은 자정에 사라지지 않으며, 시청 시간과 별도로 관리합니다. 외부 서비스나 게임 계정으로 포켓몬이 전송되지는 않습니다. 이 브라우저 데이터를 지우면 도감도 사라지므로 아직 영구적인 클라우드 저장은 아닙니다.

## 앱 안의 한글 모험

모험 시작 전에 쉬움(소리 듣고 같은 글자 찾기), 보통(낱말의 빈 글자 채우기), 어려움(글자 타일을 순서대로 눌러 낱말 만들기)을 선택할 수 있습니다. 기본은 쉬움이며 선택은 기기에 저장됩니다. 세 난이도 모두 같은 문제 ID를 공유하므로 난이도를 바꿔도 같은 날 같은 낱말을 중복 포획 실적으로 셀 수 없습니다. 어려움은 낱말 전체를 완성해야 퀘스트 1개를 기록합니다. 포켓몬 획득 조건은 난이도에 따라 달라지며, 시청 시간 보상은 기존 한글 미션과 공유하고 하루 한 번만 지급합니다.

처음 글자를 익히는 아이를 위해 한글 모험 시작·다음 문제·힌트·칭찬을 한국어 TTS로 자동 읽습니다. 보기마다 작은 ‘듣기’ 버튼이 있고, 메인 화면에는 사용 방법 듣기, 미션 카드에는 미션 듣기, 축하 화면에는 뮤츠 응원 듣기가 있습니다. 부모 메뉴에서 자동 읽기를 끄거나 0.65 / 0.8 / 1배 속도로 바꿀 수 있습니다. 기기의 한국어 합성 음성을 사용하며 원작 캐릭터 목소리는 아닙니다. Safari의 음성 재생은 사용자 버튼 입력 이후 시작하며, 기기 음성·음량·네트워크 환경에 따라 실제 재생 여부가 달라질 수 있습니다. 자동 음성이 있는 학습은 혼자 읽기 수준을 평가하는 용도로 사용하지 않습니다.

‘한글 모험 시작’은 받침 없는 낱말(나무·바다·모자·나비 등)로 그림과 낱말 맞추기, 빈 글자 채우기 5문제를 냅니다. 시간 제한과 오답 차감은 없으며 힌트를 보고 다시 풀 수 있습니다. 한국어 음성이 지원되는 기기에서는 ‘문제 듣기’를 사용할 수 있습니다. 문제 5개를 마치면 기존 한글 미션의 부모 완료 확인으로 이어집니다. 보상 시간은 부모가 설정한 해당 미션의 시간이고, 하루 중복 보상 방지는 기존 미션과 공유합니다. 이미 외부에서 완료한 한글 미션을 퀴즈로 다시 보상받을 수는 없습니다. 중간 진행은 저장하지 않으며 다시 시작하면 새 5문제가 나옵니다. 외부 학습 앱의 진도와 자동 연동하는 기능은 아닙니다.

외부 의존성이나 서버 없이 동작하는 정적 웹 앱입니다. 기록은 localStorage에 저장됩니다. 부모 메뉴는 체험판에서 비밀번호 없이 열리며 화면에 이를 안내합니다. 실제 시청 감지, 스크린 타임 차단, TV 전원 제어, 기기 간 동기화는 포함하지 않습니다.

미션을 완료하고 보상이 지급되면 뮤츠의 초능력 파동, 응원하는 뮤, 마스터볼과 보상 시간 등장 애니메이션을 표시합니다. ‘액션 다시 보기’는 화면 연출만 반복하고 보상을 중복 지급하지 않습니다. 기기의 동작 줄이기 설정을 존중합니다. 캐릭터의 정적 그림에 CSS 움직임과 효과를 더한 연출이며 영상·프레임별 캐릭터 애니메이션은 아닙니다.

기본 미션 기술은 한글 공부=염동력, 북클럽=섀도볼, 책읽기=파동탄입니다. 미션 편집 화면에서 기술을 선택할 수 있습니다. 오늘 미션으로 받은 양수 보상의 합이 60분 미만에서 60분 이상이 되는 미션 완료 시, 해당 미션 기술 이후 ‘특별 기술 보기’ 버튼으로 사이코키네시스가 추가 등장합니다. 기본 시간과 수동 시간 조절은 해금 실적에서 제외합니다. 시청·차감은 이미 모은 실적을 줄이지 않으며 다음 날에는 0분부터 다시 계산합니다. 해금과 다시 보기는 시간 보상을 추가 지급하지 않습니다.

## GitHub Pages 켜기 (저장소 소유자)

1. https://github.com/mm2wmyydc8-prog/newwork/settings/pages
2. **Build and deployment → Source → Deploy from a branch**.
3. **Branch: main**, 폴더 **/docs** 선택 후 **Save**.
4. Pages 배포가 성공하면 설정 화면의 **Visit site**로 확인합니다.

배포 성공 시 예상 주소: `https://mm2wmyydc8-prog.github.io/newwork/`

이 주소는 Pages를 켜고 배포를 마쳐야 열립니다. 저장소가 비공개이고 계정 플랜에서 Pages를 지원하지 않으면 활성화할 수 없습니다. **저장소를 자동으로 공개로 바꾸지 마세요.** 웹 페이지의 연우 이름과 캐릭터 그림은 Pages 공개 시 방문자에게 표시됩니다. 사용 기록과 사용자 추가 미션은 방문자의 브라우저에 저장되며 GitHub로 전송하지 않습니다.

## 아이폰에서 열기

Safari 주소창에 배포 주소를 입력하세요. Mac의 이 대화를 아이폰에서 열 필요는 없습니다. Safari → 공유 → **홈 화면에 추가**로 앱처럼 열 수 있습니다. 최초 접속은 네트워크가 필요하며 오프라인 실행을 보장하지 않습니다. 타이머는 절대 시작 시각으로 계산하므로 페이지를 닫았다 다시 열면 지난 시간을 반영하지만, 닫힌 동안 알림이나 TV 끄기 명령을 실행하지는 않습니다.

## 개발 검증

프로젝트 루트에서 `python3 -m http.server 8080 --directory docs`로 정적 파일을 제공할 수 있습니다. 테스트는 `node --test web-tests/model.test.mjs`로 실행합니다.
